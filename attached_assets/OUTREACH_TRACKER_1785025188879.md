# Outreach Tracker Template — Morris Law Kernel v3.5

Use this simple tracker to stay organized during your LinkedIn and email outreach.

## How to Use
Copy this into a Google Sheet, Notion database, or Excel file. Update it after every message or reply.

### Columns to Track

| Date | Name | Company / Role | Platform | Message Sent? | Reply Received? | Next Action | Status | Notes |
|------|------|----------------|----------|---------------|------------------|-------------|--------|-------|
|      |      |                |          |               |                  |             |        |       |

### Status Options (Use Dropdown)
- New Lead
- Message Sent
- Replied – Positive
- Replied – Neutral
- Replied – Negative
- Follow-up Sent
- Meeting Booked
- Pilot / LOI in Progress
- Closed – Won
- Closed – Lost
- Nurture (Long-term)

### Weekly Review Questions
- How many new conversations started this week?
- How many positive replies?
- What is the value of the current pipeline?
- Which message templates are performing best?

### Recommended Tools
- Google Sheets (free + collaborative)
- Notion (great for notes + status)
- HubSpot or Pipedrive (if you want CRM later)
- Simple Airtable base (if you like databases)

---

**Goal:** Keep momentum visible. Even a simple tracker dramatically improves follow-up discipline and conversion rates.
