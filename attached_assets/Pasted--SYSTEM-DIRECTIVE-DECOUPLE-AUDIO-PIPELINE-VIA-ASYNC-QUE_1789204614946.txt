### SYSTEM DIRECTIVE: DECOUPLE AUDIO PIPELINE VIA ASYNC QUEUE & STATE MACHINE

**Root Cause:** Synchronous execution inside `replicateClient.ts` blocks the main HTTP thread during multi-step inference (Demucs stem separation -> RVC voice synthesis -> Python MLK V3.5 mastering). Edge proxies (Cloud Run / Vercel / Nginx) drop the idle socket after 30–60 seconds, returning 504 Gateway Timeout and triggering UI failure.

**Core Mandate:** Completely eliminate synchronous waiting on the client-facing route. Offload orchestration to a state-driven queue with instant client acknowledgment (< 500ms).
