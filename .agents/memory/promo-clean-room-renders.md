---
name: Promo clean-room renders
description: A request for a brand-new GravelKing promo means no reuse of prior video, audio, timing, captions, or scene structure.
---

When the user asks for a brand-new GravelKing promo, treat it as a clean-room production. Do not crop, reframe, remix, or otherwise use a previous promo MP4 as an input. Build new timing, scene order, copy, motion, and audio from standalone approved assets.

**Why:** Reusing an earlier promo as the source after a request for a new video produced repeated variants of the same concept and broke user trust.

**How to apply:** Verify the new render script has no references to prior promo recordings or edit scripts. Inspect every scene and confirm the output has a distinct narrative and visual structure before presenting it.
